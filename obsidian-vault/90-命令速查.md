# 命令速查

> [!info] 配套 [[91-URL速查]] · 故障 [[50-故障排查]]

经常忘的命令一页搞定。所有路径默认 `/opt/douyin-spark`（root）或 `~/douyin-spark`（非 root）。

## 一键启动主菜单

```bash
curl -sL "https://gist.githubusercontent.com/mrsxs/eb80f17ecee1944c83deb5e0c33d2d78/raw/manage.sh" -o manage.sh && chmod +x manage.sh && ./manage.sh
```

## Docker 操作

```bash
cd /opt/douyin-spark

# 状态
docker compose ps

# 实时日志
docker compose logs -f

# 最近 30 行
docker compose logs --tail 30

# 启动 / 停止 / 重启
docker compose up -d
docker compose stop
docker compose restart

# 升级镜像
docker compose pull && docker compose up -d

# 进容器 shell
docker exec -it douyin-spark bash

# 删容器（保留数据）
docker compose down

# 删容器 + 数据（⚠️ 全删）
docker compose down -v
```

## 管理员密码

```bash
# 主菜单方式（推荐）
./manage.sh         # 选 [2]

# CLI 方式（新镜像）
docker compose exec app python -m app.cli reset-admin --password 你的密码

# 紧急 inline（任何镜像）
docker exec -e NEW='你的密码' douyin-spark python -c "
import os, bcrypt
from datetime import datetime
from app.db import SessionLocal, init_db
from app.models import User
init_db()
h = bcrypt.hashpw(os.environ['NEW'].encode()[:72], bcrypt.gensalt(12)).decode()
with SessionLocal() as db:
    u = db.query(User).filter(User.username == 'admin').first()
    if not u:
        u = User(username='admin', password_hash=h, is_admin=True, is_active=True,
                 expires_at=datetime(2099,12,31), max_accounts=100)
        db.add(u)
    else:
        u.password_hash = h; u.is_active = True; u.is_admin = True
    db.commit()
    print('done')
"
```

## 数据备份

```bash
# 找 volume 名
docker volume ls | grep spark

# 备份
docker run --rm -v spark-data:/data -v $(pwd):/backup \
  alpine tar czf /backup/backup-$(date +%F).tar.gz -C /data .

# 恢复
docker volume create spark-data
docker run --rm -v spark-data:/data -v $(pwd):/backup \
  alpine tar xzf /backup/backup-XXX.tar.gz -C /data
```

## SQLite 直接查

```bash
docker exec douyin-spark sh -c "sqlite3 /data/app.db '.tables'"
docker exec douyin-spark sh -c "sqlite3 /data/app.db 'SELECT id,username,is_admin,is_active FROM users;'"
docker exec douyin-spark sh -c "sqlite3 /data/app.db 'SELECT * FROM job_runs ORDER BY started_at DESC LIMIT 5;'"
```
