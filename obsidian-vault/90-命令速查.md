# 命令速查

> [!info] 配套 [[91-URL速查]] · 故障 [[50-故障排查]]

经常忘的命令一页搞定。所有路径默认 `/opt/douyin-spark`（root）或 `~/douyin-spark`（非 root）。

## 一键部署 / 运维菜单

```bash
# 部署（非交互式两步向导，重复执行 = 升级）
curl -fsSL https://raw.githubusercontent.com/mrsxs/douyin-spark/main/deploy.sh -o deploy.sh
chmod +x deploy.sh && ./deploy.sh

# 运维菜单（装 / 改密码 / 看状态）
curl -fsSL https://raw.githubusercontent.com/mrsxs/douyin-spark/main/manage.sh -o manage.sh
chmod +x manage.sh && ./manage.sh
```

## Docker 操作

```bash
cd /opt/douyin-spark

# 状态
docker compose ps

# 实时日志
docker compose logs -f

# 最近 30 行
docker compose logs --tail 30

# 启动 / 停止 / 重启
docker compose up -d
docker compose stop
docker compose restart

# 升级镜像
docker compose pull && docker compose up -d

# 进容器 shell
docker exec -it douyin-spark bash

# 删容器（保留数据）
docker compose down

# 删容器 + 数据（⚠️ 全删）
docker compose down -v
```

## 管理员密码

```bash
# 主菜单方式（推荐）
./manage.sh         # 选 [2]

# CLI 方式（新镜像）
docker compose exec app python -m app.cli reset-admin --password 你的密码

# 紧急 inline（任何镜像）
docker exec -e NEW='你的密码' douyin-spark python -c "
import os, bcrypt
from app.db import SessionLocal, init_db
from app.models import User
init_db()
h = bcrypt.hashpw(os.environ['NEW'].encode()[:72], bcrypt.gensalt(12)).decode()
with SessionLocal() as db:
    u = db.query(User).filter(User.username == 'admin').first()
    if not u:
        u = User(username='admin', password_hash=h, is_admin=True, is_active=True,
                 max_accounts=100)
        db.add(u)
    else:
        u.password_hash = h; u.is_active = True; u.is_admin = True
    db.commit()
    print('done')
"
```

## 看 admin 密码（首次启动自动生成的）

```bash
docker compose logs | grep -A 8 "管理员账户"
```

## 数据备份

```bash
# 找 volume 名
docker volume ls | grep spark

# 备份
docker run --rm -v spark-data:/data -v $(pwd):/backup \
  alpine tar czf /backup/backup-$(date +%F).tar.gz -C /data .

# 恢复
docker volume create spark-data
docker run --rm -v spark-data:/data -v $(pwd):/backup \
  alpine tar xzf /backup/backup-XXX.tar.gz -C /data
```

## SQLite 直接查

```bash
docker exec douyin-spark sh -c "sqlite3 /data/app.db '.tables'"
docker exec douyin-spark sh -c "sqlite3 /data/app.db 'SELECT id,username,is_admin,is_active FROM users;'"
docker exec douyin-spark sh -c "sqlite3 /data/app.db 'SELECT * FROM job_runs ORDER BY started_at DESC LIMIT 5;'"
```

## 防 CDN 缓存拉取

raw.githubusercontent.com 缓存约 5 分钟，急着要最新的就带 commit sha：

```bash
SHA=$(gh api repos/mrsxs/douyin-spark/commits/main --jq .sha)
curl -fsSL "https://raw.githubusercontent.com/mrsxs/douyin-spark/$SHA/manage.sh" -o manage.sh
```


## 本地开发

```bash
# 启动（改代码自动重载）
python run.py --port 8765 --reload

# 自证（提交前必跑）
pytest -q
ruff check app/ tests/ run.py

# 单个测试文件 / 单个用例
pytest -q tests/test_trigger.py
pytest -q -k "send_interval"

# 后台跑
nohup python run.py > /tmp/spark.log 2>&1 &
ps aux | grep run.py | grep -v grep | awk '{print $2}' | xargs kill 2>/dev/null
```

## 用户管理（CLI）

```bash
# 容器里
docker compose exec app python -m app.cli list-users
docker compose exec app python -m app.cli reset-password --username <名字>
docker compose exec app python -m app.cli set-admin --username <名字>        # 提权
docker compose exec app python -m app.cli set-admin --username <名字> --off  # 撤销

# 本地源码态（去掉 docker compose exec app 前缀即可）
python -m app.cli hash-password 你的密码     # 生成 .env 用的 bcrypt 哈希
python -m app.cli gen-secret                # 生成 SECRET_KEY
```
