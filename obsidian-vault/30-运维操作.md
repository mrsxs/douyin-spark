# 运维操作

> [!info] 上下文 [[00-总览]] · 部署 [[20-部署流程]] · 故障 [[50-故障排查]]

最常用的服务器端操作。所有操作都通过主菜单 `./manage.sh` 完成。

## 重置管理员密码

> [!tip] 场景
> 忘记了首次自动生成的密码 / bcrypt 哈希因 shell quoting 损坏导致登录失败 / 想换个密码

### 方法 1：主菜单（推荐）

```bash
./manage.sh
# 选 [2]
# 提示：用户名（默认 admin）→ 直接回车
# 输入新密码（隐藏） → 再次确认
# ✓ 已重置 admin 密码
# hash 前缀: $2b$12$xxxxxxxxxxx...
```

立即用新密码登录。**不需要重启容器**，**不需要 pull 新镜像**。

### 方法 2：用 cli（需要 2026-04 之后的镜像）

```bash
docker compose exec app python -m app.cli reset-admin --username admin --password 你的密码

# 或交互式（密码不进 history）
docker compose exec app python -m app.cli reset-admin
```

### 方法 3：紧急 inline（最底层兼容）

```bash
docker exec -e NEW='你的密码' douyin-spark python -c "
import os, bcrypt
from datetime import datetime
from app.db import SessionLocal, init_db
from app.models import User
init_db()
h = bcrypt.hashpw(os.environ['NEW'].encode()[:72], bcrypt.gensalt(12)).decode()
with SessionLocal() as db:
    u = db.query(User).filter(User.username == 'admin').first()
    if not u:
        u = User(username='admin', password_hash=h, is_admin=True, is_active=True,
                 expires_at=datetime(2099,12,31), max_accounts=100)
        db.add(u)
    else:
        u.password_hash = h; u.is_active = True; u.is_admin = True
    db.commit()
    print('done')
"
```

## License 续期

> [!tip] 场景
> 现有 license 快过期 / 已过期需要续费 / 升级到不同 tier

### Step 1：本地签新 license

```bash
cd /Users/apple/item
python3 tools/issue_license.py --days 365 --tier pro --note "续费 2027-04"
# 复制输出的长字符串
```

详见 [[40-开发流程#签发 License]]

### Step 2：服务器主菜单 [3]

```bash
./manage.sh
# 选 [3]
# 显示当前 license 信息
# 提示：粘贴新 license
# 自动备份旧 .env 到 .env.bak.YYYYMMDD_HHMMSS
```

### 失败回滚

如果新 license 验证失败：
```bash
cd /opt/douyin-spark
ls .env.bak.*       # 找最新备份
cp .env.bak.YYYYMMDD_HHMMSS .env
docker compose restart
```

## 查看日志

### 主菜单 [4]
```bash
./manage.sh
# 选 [4]
# 显示 docker compose ps + 最近 30 行 logs
```

### 实时跟踪
```bash
cd /opt/douyin-spark
docker compose logs -f
```

### 按关键词
```bash
# 看 admin 密码（首次启动）
docker compose logs | grep -A 8 "管理员账户"

# 看 License 验证
docker compose logs | grep -A 5 "License 已验证"

# 看错误
docker compose logs | grep -iE "(error|warning|❌|⚠)"

# 看自动续火花的执行结果
docker compose logs | grep -E "\[auto\]"
```

## 数据备份

### 备份 volume（含所有 cookies / 私钥 / DB / 模板）

```bash
docker run --rm \
  -v 系统的volume名:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/spark-backup-$(date +%F).tar.gz -C /data .

# 找 volume 名：docker volume ls | grep spark
```

### 备份 .env 配置

```bash
cp /opt/douyin-spark/.env ~/spark-env-$(date +%F).bak
```

### 恢复

```bash
# 1. 装 docker + 拉 compose 文件
# 2. 恢复 volume
docker volume create spark-data
docker run --rm -v spark-data:/data -v $(pwd):/backup \
  alpine tar xzf /backup/spark-backup-XXX.tar.gz -C /data
# 3. 恢复 .env
# 4. docker compose up -d
```

## 停止 / 启动

```bash
docker compose stop      # 停（保留数据）
docker compose start     # 启
docker compose restart   # 重启
docker compose down      # 停 + 删容器（数据 volume 保留）
docker compose down -v   # 停 + 删容器 + 删数据 volume（⚠️ 全删）
```

## 升级到新版本

```bash
docker compose pull       # 拉新镜像
docker compose up -d      # 重建容器（自动用新镜像，数据 volume 不变）
```

或主菜单 [1] 选 N（不重新配置） → 自动 pull + up -d。
