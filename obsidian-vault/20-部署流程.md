## 一键部署（推荐）

服务器上**一行命令**启动主菜单，全程交互向导：

```bash
curl -sL "https://gist.githubusercontent.com/mrsxs/eb80f17ecee1944c83deb5e0c33d2d78/raw/manage.sh" -o manage.sh && chmod +x manage.sh && ./manage.sh
```

> [!tip] 强制最新版（绕过 Gist CDN 缓存）
> `https://gist.githubusercontent.com/mrsxs/eb80f17ecee1944c83deb5e0c33d2d78/raw/<commit-hash>/manage.sh`
> 获取最新 hash: `gh api gists/eb80f17ecee1944c83deb5e0c33d2d78 --jq '.history[0].version'`

## 首次部署 - 选 [1] 后流程

### Step 1：本地签发 License

```bash
cd /Users/apple/code/python/抖音续火花
python3 tools/issue_license.py --days 365 --tier pro --note "服务器A"
```

输出一长串 `eyJ...xx==.yyy...`，**复制**。详见 [[40-开发流程#签发 License]]

### Step 2：服务器主菜单选 [1]

向导依次问 3 个：

1. **LICENSE_KEY** - 粘贴 Step 1 的输出
2. **DOUYIN_CAPTCHA_KEY** - 滑块识别服务 key（可回车跳过）
3. **ADMIN_PASSWORD** - 自定义（隐藏输入 + 二次确认）或回车让系统随机生成

脚本自动执行：
- 下载 docker-compose.yml
- `docker pull mrsxs/douyin-spark:latest`
- 用镜像里的 bcrypt 算密码哈希
- 写入 `.env`（chmod 600）
- `docker compose up -d`
- 健康检查 60s 内通过

### Step 3：访问

```
http://服务器IP:8765/login
admin / 你设的密码
```

> [!warning] 内网 IP
> 如果服务器只有内网 IP（如 `10.x.x.x`），从外部访问需要：
> - 用云服务商提供的公网 IP
> - 或绑域名 + 反代（推荐 Caddy）

## 升级（已部署过的服务器）

主菜单选 [1]，会检测到已有 `.env`，问"重新配置？[y/N]" → 直接回车（N） → **只 pull 新镜像 + restart**，不动配置。

或者跳过菜单直接：

```bash
cd /opt/douyin-spark
docker compose pull
docker compose up -d
```

## HTTPS 反代（推荐生产）

```
# /etc/caddy/Caddyfile
yourdomain.com {
    reverse_proxy localhost:8765
}
```

同时改 `.env`：
```
COOKIE_SECURE=true
```

`docker compose restart` 生效。

## 镜像源选择

`docker-compose.yml` 默认用 **Docker Hub**（公开免登录）：

```yaml
image: mrsxs/douyin-spark:latest
```

如果想用 GHCR（需先 `docker login ghcr.io`）：
```yaml
image: ghcr.io/mrsxs/douyin-spark:latest
```

两个仓库内容完全一致，每次 GitHub Actions 同步推送。详见 [[40-开发流程#自动构建链路]]
