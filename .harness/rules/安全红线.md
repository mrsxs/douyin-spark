# 安全与凭证红线

> 本项目持有大量高敏资产：用户抖音 cookies、抖音私钥/签名密钥、RSA License 签名私钥、SECRET_KEY、SMTP 密码。任一泄露后果严重。**这一份是硬约束，违反即阻断。**

## 绝不入 git / 绝不进镜像

以下已在 `.gitignore`，提交前再确认未被强加：

- `license_private_key.pem`、`*_private_key.pem` — **License 签名私钥**。泄露 = 任何人可伪造永久 license。已 chmod 600，永不进 Docker 镜像。
- `.env`、`.env.local` — 真实凭证。只有 `.env.example` 进 git（占位、空值）。
- `data/` — 整个运行时目录：`app.db`、`.secret_key`、各账户 `cookies.json` / `security.json`（Fernet 加密）。
- `*.douyin_cookies.json`、`*.douyin_security.json`、`*.douyin_init_req.bin` 等账户态文件。
- `.claude/`、`fetch_security.py`、`test_fetch_http.py`、`web_panel.py`、调试输出。

## 凭证只走 .env / config

- 所有密钥从 `app/config.py` 的 `Settings` 读，其它模块 `from .config import settings`。
- 新增敏感配置：加进 `Settings` + 在 `.env.example` 留**空占位**（带注释说明怎么生成），**绝不**把真实值写进 `.env.example` 或代码默认值。
- `SECRET_KEY` 缺失时会自动落盘到 `data/.secret_key`（chmod 600）——生产必须在 `.env` 显式设置，不要依赖自动生成。
- SMTP 密码等存库字段用 `app/crypto.py` 的 Fernet 加密，不明文存 DB。

## 日志 / 响应脱敏

- 日志、异常、返回给前端的内容里**禁止出现** cookies、私钥、SECRET_KEY、SMTP 密码、完整抖音 token。最多打长度或前几位。
- 前端错误统一过 `_safe_err()`（见 `编码规范.md`），不泄露 traceback / DB 错误 / 内部路径。

## Web 安全

- 改数据的请求必须带 CSRF token（`csrf_mw.py`）；session 用 itsdangerous 签名。
- 生产 https 下 `.env` 设 `COOKIE_SECURE=true`。
- `/api` 归属校验交给 `deps`（`require_active` + `get_account_owned`），不要绕过。
- License 校验只在开发用 `SKIP_LICENSE_CHECK=1` 跳过，**禁止**把跳过逻辑带进生产路径或镜像。

## 提交前自检（每次 commit/push）

```bash
git diff --cached --name-only          # 确认没有 data/ .env *.pem 混入
git diff --cached | grep -iE 'secret|password|private[_ ]?key|cookie|BEGIN .*PRIVATE'  # 应无真实值命中
```
有疑似命中先停下核实，别赌。
