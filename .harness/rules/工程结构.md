# 工程结构与落点规范

> 本项目是 **抖音 IM 续火花 SaaS**：FastAPI + SQLAlchemy 2.0 + SQLite(WAL)，Jinja2+Alpine.js 前端，Docker 部署。
> 业务/架构详解见 `obsidian-vault/`（知识层），本规则只管「新代码放哪、依赖往哪走」。

## 目录布局（真实）

```
抖音续火花/
├── run.py                 启动入口（python run.py --port 8765）
├── douyin_im.py           抖音 IM 协议层（签名/发消息/扫码/拉联系人）—— 82KB，独立于 app/
├── fetch_security.py      一次性本地脚本：抓私钥（不部署，已 gitignore）
├── app/                   Web 应用包
│   ├── main.py            FastAPI 工厂 + lifespan + 全局异常处理 + admin upsert
│   ├── config.py          pydantic-settings，唯一读 .env 的地方
│   ├── db.py              engine + SessionLocal + Base + init_db（建表/索引/迁移）
│   ├── models.py          所有 ORM 模型（User/DouyinAccount/Schedule/JobRun/...）
│   ├── deps.py            FastAPI 依赖（require_active / get_account_owned 等）
│   ├── security.py        密码 hash + session + CSRF
│   ├── csrf_mw.py         ASGI CSRF 中间件
│   ├── crypto.py          Fernet helper（加密 SMTP 密码等）
│   ├── scheduler.py       后台线程：30s 扫表触发续火花 + 每日 cookies 体检
│   ├── trigger.py         核心业务：续火花/批量发送 + 账户级互斥锁
│   ├── notify.py          站内通知(DB) + 邮件(线程池)
│   ├── storage.py         每账户独立目录管理（AccountCtx）
│   ├── templates_service.py  模板 DB 访问层
│   ├── cli.py             CLI 工具（hash-password / gen-secret / reset-admin）
│   └── routers/           路由层（薄，只编排）
│       ├── auth.py        登录/注册/激活
│       ├── dashboard.py   用户主面板（HTML）
│       ├── login_flow.py  扫码登录流程
│       ├── api.py         JSON API（前缀 /api，每请求带 account_id）
│       └── admin.py       管理后台
├── templates/             Jinja2 模板（按页面分目录）
├── lib/                   Node 签名依赖（Request.proto / a_bogus_core.js）
├── data/                  运行时数据（gitignore，含敏感）
└── obsidian-vault/        知识层文档（架构/部署/抖音协议算法）
```

## 落点规则（新代码放哪）

| 要加的东西 | 放哪 |
|-----------|------|
| 新的 JSON 接口 | `app/routers/api.py`，挂在 `/api` 前缀下，第一参带 `account_id` |
| 新页面（HTML） | `app/routers/dashboard.py` 或新 router + `templates/` 下模板 |
| 新业务逻辑（续火花/发送相关） | `app/trigger.py`，不要写进 router |
| 新 ORM 表/字段 | `app/models.py` 加模型；建表/索引迁移写进 `app/db.py:init_db()` |
| 抖音协议/签名/HTTP 调用 | `douyin_im.py`，**不要**让 `app/` 直接拼抖音请求 |
| 新配置项 | `app/config.py` 的 `Settings`，并同步 `.env.example` |
| 新的定时/后台任务 | `app/scheduler.py` |
| CLI 子命令 | `app/cli.py` |

## 依赖方向（必须遵守）

```
routers/  →  trigger / notify / templates_service / deps   （路由只编排，不写业务）
trigger   →  douyin_im / storage / models / notify
app/*     →  config / db / models                          （基础设施）
douyin_im.py  独立，不 import app.*                          （协议层不依赖 Web 层）
```

- **router 保持薄**：参数校验 + 调 service + 包装响应。业务逻辑下沉到 `trigger.py`。
- **抖音协议只在 `douyin_im.py`**：`app/` 通过 `import douyin_im as dy` 调用，禁止在 `app/` 里直接拼 imapi.douyin.com 请求或写签名逻辑。
- **`config.py` 是唯一 .env 入口**：其它模块 `from .config import settings`，不要散落 `os.getenv`。
